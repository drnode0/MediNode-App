## ⚠️ オーナーが手でやること（これをやるまで完成しない）

### 1. Vercel に `TOWER_EMAILS` を置く

https://vercel.com/dashboard → プロジェクト → Settings → Environment Variables

```
TOWER_EMAILS=<オーナーのメール>
```

**置くまでは分離が効かない。** `TOWER_EMAILS` が空のあいだ、蔓は `EARLY_ACCESS_EMAILS`（マルチ部署検索と共用）を見る。置いた瞬間にそちらだけを見る。

### 2. 蔓が他の人に開いていないか `/admin` の台帳で確認する

`TOWER_EMAILS` を置いても、**まだ2つの経路で他人に蔓が開きうる**。

- **機能トグル**：台帳で誰かに `tower` を個別付与していないか
- **レガシーの `early_access`（boolean）**：`LEGACY_BOOLEAN_FEATURES = ['multi_department', 'tower']` なので、**旧フラグが true の人には蔓が開く**。これは段A（機能別の先行体験）が移行のために意図的に残した互換で、勝手に外すと他セッションの設計を壊すため触っていない

「本当に自分だけ」にしたいなら、台帳で旧フラグの立っている人を機能別トグルへ移し替えるのが筋。

### 3. 実機で見た目を確かめる

コンポーネントテストの基盤が無く、蔓はフラグの内側にあるので**確認できるのはオーナーだけ**。見るところ：

- 開くと**穂先（今日）から始まる**か
- 下へスクロールして過去を辿れるか
- **越えたものの目次**（チップ）をタップして飛べるか
- 葉が潰れていないか（旧構造では95枚で潰れた）
- 久しぶりに開いたとき、成長リプレイが**画面の中で**起きるか

高さの見え方が変わっている。葉274枚なら **82cm → 57.9cm**、番傘が「越えた」から未到達に戻る。定数変更の意図した結果で、葉の枚数＝記録は1件も減っていない。

## 壊してはいけない不変条件

- **`VineScene` の `<svg>` は `viewBox` と `width`/`height` を同値にする。** 崩すと `scrollTop`（CSS px）と `leafY`（viewBox単位）がズレ、深くスクロールするほど葉が消える。`w-full` や `max-w-*` を足さないこと（コード上に⚠️コメントあり）
- **`COMPOUND_START_LEAVES × COMPOUND_RATE === 1`。** 崩すと複利開始と同時に減速する。テストで固定済み
- **葉を間引かない。** 窓の外を描かないのは間引きではない
- **色褪せ・未読・連続日数を数えてUIに出さない**（負債台帳化の禁）
- **画面文言は `src/lib/vine-copy.ts` を通す。** 直書きすると六つの禁の走査に載らない

## フェーズ3以降への地雷（最終レビューが指摘）

1. **地下茎と `leafY(index, total)` の契約衝突。** いまの `total` は「葉の総数＝地面の位置」。地下茎を入れると地上の葉数と幾何の `total` が別物になるので、**先に引数名を「地上の葉数」に確定させないと全部のy座標が静かにズレる**
2. **点景（`sceneryMarks`）と `sceneMarks` が同じ右余白を奪い合う。** 点景を足す時点で右レーンのレイアウトを1本の関数に統合すること
3. **§8「測るのをやめる」が未実装。** 葉3274枚で 1822km を表示する破綻経路が生きている
4. **印のラベルが右端で無言で切れうる**（`textAnchor` 無し・`x = W - 92` 固定）
5. **目次にはアリが残るが、蔓の印からは間引かれる**（アリとテントウムシは葉数が1違いで永久に14px間隔のため）。アリをタップすると印が無い場所へ飛ぶ

## 判断の記録（蒸し返さないために）

- **蔓の開放判定は段Aの `tower` フラグに一本化した。** 実装中に別セッションが「機能別の先行体験」を main へ入れており、同じ問題をより良く解いていたため、自前の `vine-access.ts` は破棄した。**並行システムを作らないこと**
- **次の実物は穂先の上に淡く置く。「あと◯◯」の寸法線と数字は出さない**（数字で追い立てないため）。正典§7に従い、直近に葉が増えているときだけ出す
- **持ち込んだ知識は地下茎にする**（フェーズ3）。地下に本葉は生えないので、地下にあるのは「まだ芽を出していない知識」。読み返す・思い出すと地上に生まれ直す。**バックフィルは一瞬でも地上に出すには時間がかかる**ので、序盤が食い尽くされない
- **雲の先＝測るのをやめる＋季節の点景と出会う。** 「比べる相手が自分の去年になる」案は却下（姿がなく、比率になり、数字で集計しない思想と衝突する）
