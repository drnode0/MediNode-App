### フェーズ5で入ったもの（要点）

- **暦12項目**（`vine-scenery.ts` の `SCENERY_ALMANAC`・固定月日・JST解釈・自然物のみ）: 初日の出1/1・梅2/20・桜3/28・つばめ4/20・若葉5/20・蛍6/15・蝉しぐれ7/20・流れ星8/12・名月9/15・雁10/15・紅葉11/15・初雪12/10。満月は毎月あって印が安売りになるので名月だけ（正典§15の「暦は実装計画で詰める」の回答）
- **`sceneryMarks(leaves, nowIso)`**: 点景を葉と葉の間に時間割合で置く。⚠️ 渡すのは `leafSteps` 済みの地上の葉が契約。最初の葉より前は置かない。最後の葉より新しい分は穂先の上1葉ぶんに圧縮（止まった人にも何かが起きる）。**休みの区間は点が柱状に重なる＝空白が空白として読める**
- **`laneMarks`（右レーン統合＝地雷2解消）**: 実物の印・点景・地下が尽きた日のラベル配置を1本で決める。優先度は 地下が尽きた日＞実物の印＞点景、各新しい側優先。**間引くのはラベルだけで刻み・点は全件描く**（地雷5解消：目次から飛んだ先に必ず刻みがある）。旧 `sceneMarks` は削除
- ラベルは右端アンカー（`textAnchor="end"`）＝長い名前でも右で切れない（地雷4解消）
- 点景は通知しない（push系のコードには一切触れていない）。空と住人の絵はアセットフェーズ送り——それまで点景は薄墨の点＋名前

### フェーズ4で入ったもの（要点）

- **`resolved`（CQ→ナレッジ解決＝+2mm）**: `ingestRecords` が `knowledgeLevel` を `TowerState.levels` に記憶し、前回❓CQ→今回💡ナレッジの遷移を見つけたら積む。**遷移は検索/バックフィルでそのレコードに再会した時に検出される＝昇格の瞬間ではない**。レベル未設定の人には何も起きない（ペナルティゼロ＝正典§9）
- **`attempt`（クイズで「まだ」）**: 台帳に積むが**葉ではない**——高さ・リプレイ・枚数・目次はすべて `leafSteps`（attempt抜き）基準。画面では**穂先の未展開葉（巻き葉）**として最大7個描く（数字は出さない）。思い出せたら（recall/repolish）芽は消えて葉が生える
- **読み返しの濃度**: `medinode_reader_rereads_v1`（PERSONAL_DEVICE_KEYS登録済み）に日付と回数だけ持つ（歩は積まない）。90日以上あけた再読で輪郭の線が1段濃くなる（3段階）。褪せた青葉は最後のクイズより新しい再読で**色が半分**戻る（照りは出ない）
- 葉シートの行為ラベルに「解決した」、凡例も更新

### 生まれ直しの修正（2026-08-03・オーナー実機の「全く動いていない」報告で発覚）

フェーズ3で「既知の限界（影響小）」としていた **(id,kind) 一生に1回が地下の歩まで見て生まれ直しを塞ぐ問題**は、実際には致命的だった——移行でアプリ内の read/recall の歩ごと地下に沈むため、**よく触っている知識ほど何をしても生えない**。さらに `recallKind` がクイズ統計（移行で消えない）だけを見るため、90日以内に正解済みの問題は正解しても何も積まれなかった。

修正:
- **重複判定を地上スコープに**: 地上への追加候補は地上の歩とだけ照合（生まれ直し＝正典§7）。地下に落ちる候補（古い日付のwrote再取込）は全歩照合のまま（台帳の水増し防止）
- **`recallKindFor(state, id, prev, now)` 新設**: 地上にrecallが無ければ「この蔓での初回の即答」としてrecall。QuizCard/DailyQuestionCard はこちらを使う（統計だけを見る旧 `recallKind` は純関数として残置）
- 「一生に1回」は**地上の中で**引き続き成立（同じ葉が二重に生えることはない）

## 壊してはいけない不変条件

- **`VineScene` の `<svg>` は `viewBox` と `width`/`height` を同値にする。** 崩すと `scrollTop`（CSS px）と `leafY`（viewBox単位）がズレ、深くスクロールするほど葉が消える。`w-full` や `max-w-*` を足さないこと（コード上に⚠️コメントあり）
- **`COMPOUND_START_LEAVES × COMPOUND_RATE === 1`。** 崩すと複利開始と同時に減速する。テストで固定済み
- **葉を間引かない。** 窓の外を描かないのは間引きではない
- **色褪せ・未読・連続日数を数えてUIに出さない**（負債台帳化の禁）
- **画面文言は `src/lib/vine-copy.ts` を通す。** 直書きすると六つの禁の走査に載らない

- **口上の出口**: 段3は自動で消えず「今日の1問にこたえて 最初の葉をひらく」（onGoQuiz）と「じぶんの蔓を見る」の二択——何をしたらいいか迷子にしない。**文言はオーナーと議論して磨き中（未確定）**

### 第7波＝3視点パネルの反映（2026-08-04・merge=5bd1ece）

オーナー「全体的に体験がとっても悪い。惜しいけどピースが掴めていない」→ ゲームクリエイター／初見の医師／アートディレクターの3視点を独立に走らせ、8つの不満が**本当は4つの根本**だと判明。

**根本1: カメラが無かった（最重要）**
唯一の画面制御が `maxHeight:'70vh'` だけで、地面の位置が葉数で動いていた。葉3枚＝蔓28px・空白が箱の54%。
→ `sceneOffset(aboveTotal, depth, viewportH)` を新設し、シーンが画面より低いときは**上に余白を足して地面を画面の下寄りに固定**。⚠️「全体を1画面に収める」ではない（1葉=14pxは不変・長いときの挙動は不変）。leafY/groundY/sceneHeightPx/visibleRange/markPositions/laneMarks/sceneryMarks は末尾に `offset` を取る（既定0なので既存テストは不変）。**VineScreen と VineScene は同じ offset を使うこと**——ズレると目次の飛び先が全部狂う。

**根本2: 物差しが2本あった**
縦軸は葉の番号、絵の大きさは `葉数×14×0.85・上限64px` という別物差し。実寸80倍差のアリと一升瓶が画面では1.8倍差、しかも全部が地面から浮いていた。
→ 絵の高さ＝**地面からその朱線までの距離**の1本に統一。さらに `GROUND_GAP` を 40 → `PX_PER_LEAF`（=14）に。40pxは「葉0枚ぶんの高さ」を無料で足しており、丈が `40+(n-1)*14` と非線形で、**小さい実物ほど誤差が大きかった（アリ +94%）**。同値なら丈 = n*14px = n*2mm で完全に線形。
→ PNGごとの余白率（インクが画像高の31%〜77%）を `MILESTONE_ART` の topFrac/hFrac で補正。これが無いと5mmのテントウムシが5mmのアリより小さく描かれる。

**根本3: 墨絵に光源と濁色を持ち込んでいた**
`.obi` の `box-shadow 0 0 16px 10px` が白い暈を出し、帯の芯が紙より明るかった（夜1.85:1）。夜トーン `#CBB58C` は薄墨のコントラストが1.90:1で**文字が物理的に読めない**。ダークモードは時刻を無視して常時最濃を出していた。
→ 光る帯を全廃（口上の詞書は絵の外＝フッターへ）。紙の色は `--washi` 一箇所で決め、`.frame`/`.tanzaku` が同じ変数を見る。色をコントラストで決め直し: 朱 `#A8342A`／薄墨の文字 `#5F5849`・図形 `#7C7462`／苔 `#55643C`／銀鼠 `#9AA096`／夜 `#E3D6B6`。

**根本4: 主役の解像度不足**
葉は実効8.7〜24pxで、4状態の差が全部「塗りの明度」だった。地下茎は**画像の上45%が地面より上に描かれ、本物の幹の隣に淡いゴースト新芽が重なっていた**（＝「根の形が気に入らない」の正体）。マスクも上下逆で、ひげ根を消して走茎の棒だけ残していた。
→ 葉に20pxの床＋照りは1.18倍＋金泥の縁、褪せは輪郭を `fade>=0.3` から。地下茎は `overflow:hidden` の窓で地上を切り落とし、マスクを反転。

**あわせて直した致命傷（初見レビューが発見）**
- **葉0枚のユーザーは「今日の1問」へ行く導線が画面に存在しなかった** → フッターに常設
- **葉4枚に達した瞬間、アリのラベルと絵が永久に消えていた**（laneMarksが新しい側優先）→ 最初の1つは無条件でラベルを残す
- 口上 11.2秒→5秒、見本 500枚→60枚（他人の巨木を見せてから0枚を渡す約束違反）
