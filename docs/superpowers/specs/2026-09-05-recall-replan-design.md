## 2. 分野ページ（指摘 A・B）

### 2.1 構造

```
◯芯96  呼吸  RESPIRATORY
       Exchange　主張 178 ・ 残した 45 ・ 深く残した 17　離れかけ 11
       [この分野を確かめる（11）] [戻る]
────────────────────────────────────────────
○未着手 ○読んだ ●残した ◉深く残した ●離れかけ            ← 凡例（既存の点の部品）
[急性呼吸不全 Essenti… 4] [酸素療法はどのように…] [人工呼吸…]  ← 記事の目次（貼り付き）
┃ 📚 急性呼吸不全 Essentials  71              記事を読む ›  ← 記事の見出し（帯・貼り付き）
  1 定義と病態
  ○ ○ ● ○ ○ ○ ● ◉ ○ ○
  2 臨床像
  ○ ● ● ○ ○ ● ○ [●] ○
  ┃ CO2ナルコーシスでは、頭痛、振戦、痙攣、傾眠、…     開く ›   ← 押した点の1行
  ┃ 離れかけ　もう一度押すと確かめる
  3 診断と検査
  …
┃ 💡 酸素療法はどのように使い分ける？  39        記事を読む ›
  …
```

- **見出し**（紋章 96px・和名・英名・族・件数・ボタン2つ）は今のまま。紋章を押すと隠しコマンド（§4）
- **凡例**: 見出しの下に1行。点の部品（`RecallDot`）を 9px で5つ並べ、語を添える。一覧（`RecallDex`）では「Recall とは」の折りたたみの中にだけ置く（§3）
- **記事の目次**: 丸いチップの横並び・横スクロール・`position: sticky; top: 0`。中身は記事名の先頭 14 字（16字超なら「…」）と、離れかけがあればその数（金）。押すと記事の見出しへ `scrollIntoView({ block: 'start' })`。いま画面にある記事のチップを濃くする（`IntersectionObserver`）。記事が1つだけでも出す（統一）
- **記事の見出し**: 絵文字つきの `pageTitle`・主張数・「記事を読む ›」（既存 `onRead`）。本文の色・15px・500・左に 3px の縦線・`color-mix(ink 6%)` の帯。`sticky` で目次の下（`top: 目次の高さ`）に貼り付く
- **節**: 番号は付けず、`sectionHeading` をそのまま（実データは「1. 定義と病態」と番号を持つ）。11px・薄い色。見出しが空の節（`sec0`）は見出しを出さない
- **点の列**: 主張1つ＝点1つ。**14px・間隔 6px・当たり判定は `::after` で 26px** に広げる。並びは今の行の順（節の中は作成順 → claimId）。見た目は `RecallDot`（5段）そのまま。行（`.row`）は廃止
- **押した点の1行**: 点を押すと、その節の点の列の直下に「本文1行（`line-clamp-1`）・状態の語・『開く ›』」。左に 2px の縦線（アクセント色）。離れかけなら状態の語の後ろに「もう一度押すと確かめる」。開いている1行は分野ページで1つだけ（別の点を押すと差し替わる）。同じ点をもう一度押す・「開く ›」を押す → カード（離れかけ＝quiz、他＝view。既存 `onRow` と同じ振り分け）。押した点は輪郭 2px（アクセント色）
- **カードを答えたあと**: 点がその場で濃くなる（既存の 600ms 遷移）。1行は閉じる
- **「離れかけを順に確かめる」**（一覧の帯）は今のまま。分野ページに移ってカードが順に出る。点の列はその間も見える
- **「戻る」**: 一覧へ（既存。スクロール位置の復元も既存）

### 2.2 高さの目安

実データの呼吸（178件・6記事）で 2,172px（試作の実測）。今の 13,523px の 16%。

### 2.3 モデル（`dex.ts`）

`PageModel` に足す:

```ts
pages: Array<{
  pageId; title; n
  escaping: number          // 目次のチップの数
  sections: Array<{ sectionKey; heading; rows: Array<{ claimId; body; look }> }>  // 既存

```

`rows` はそのまま使う（点の列の1点＝`row`）。「押した点」は部品の state（`selected: { claimId } | null`）で持ち、モデルには入れない。

## 4. 隠しコマンドの段（指摘 D）

### 4.1 段と動線

```
分野ページ ─紋章─▶ 球（その惑星だけ） ─「さらに宇宙へ」─▶ 宇宙（遠景）
    ▲                 │ 「戻る」                      │ 惑星を押す → 中央に寄る（中景）
    └─────────────────┘                              │ もう一度押す → 球（宇宙から）
    ▲                                                │
    └──────── 宇宙の「戻る」（覆いを閉じる）◀──────────┘    球（宇宙から）の「戻る」→ 宇宙へ
```

覆い（`RecallLift`）の状態は純関数 `lift-phase.ts` で持つ:

```ts
type LiftPhase =
  | { kind: 'sphere'; slot: number; from: 'page' }
  | { kind: 'space'; focus: number | null }          // focus＝中央に寄せた惑星（中景）
  | { kind: 'sphere'; slot: number; from: 'space' }
```

| いる場所 | 下のボタン | 上の文字 | 背景タップ・ピンチイン・ホイール下 |
|---|---|---|---|
| 球（分野ページから） | 「戻る」「さらに宇宙へ」 | 和名・英名（今のまま） | 何もしない（`lockNear`。球から勝手に出ない） |
| 宇宙・遠景 | 「戻る」 | なし | 背景タップ＝族の寄りを解く。ピンチ＝倍率 |
| 宇宙・中景（惑星に寄った） | 「戻る」 | なし（名前は惑星の下・§4.4） | ピンチイン＝遠景へ。背景タップ＝何もしない |
| 球（宇宙から） | 「宇宙へ戻る」 | 和名・英名 | 何もしない（`lockNear`） |

Esc・タブを離れる・カードとの譲り合いは今の `RecallLift` のまま。宇宙で惑星の点（主張）は押せない（球へ入ってから）。

### 4.2 球（R5・案4）

- `RecallField` に **その惑星だけ**を渡す（`planets.filter(slot)`）。配置は星団（§4.3）の座標を使うが、1つしか無いので見え方は今の近景と同じ（惑星が中央）
- 描くもの: 芯・点（5段）・輪郭の円。**消すもの**: 境目の円・境目の名前・記事名。扇形の弧は **触れた（pointerdown）から 2.6 秒、最後の 600ms で薄れる**（`fanAlpha`）
- 回し方: 横＝輪と芯（`handYaw`）、縦＝見下ろし（`rotX`）。**頭打ちを外す**（`free`）。慣性は既存
- 縦に回すと輪が裏返り「高度＝保持力」の読みが崩れる、が 09-04 の頭打ちの理由だった。球は眺める段なので許容する（オーナー指示「縦横斜め縦横無尽」）

### 4.3 宇宙（R6〜R9）

配置 `'cluster'`（`FieldMode` に足す。純関数 `field-cluster.ts`）:

- 族の中心7点: 黄金角の螺旋で球面に置き、半径 `FAMILY_R = 0.5`。族の順は `CoreKind` の定義順
- 惑星: 族の中心 ＋ 席番号のハッシュで決まる固定のずれ（半径 `CLUSTER_SPREAD = 0.3` の球の中、立方根で内側に溜めない）。開くたびに変わらない
- 大きさ: `planetRadius(n, max)` のまま。**重なり回避（`fitScale`）は星団では掛けない**（掛けると惑星が 5px になった）
- カメラ: 遠景＝倍率 `CLUSTER_ZOOM 2.4`・見下ろし `CLUSTER_PITCH −0.55`・焦点は原点。中景＝倍率 `CLUSTER_MID_ZOOM 5`・焦点は寄せた惑星。自転 `IDLE_SPIN` は遠景・中景で今のまま
- 空の席: **ガス**（R8）。`drawNebula`: 1席2枚、中心から `S×(0.3〜1.1)` ずらした半径 `S×(1.3〜2.0)` の放射状グラデーション（`pal.outline` → 透明）、不透明度 `0.07 × alphaGain × depth`、毎秒 0.04 rad で漂う。`reduced` では止める。粒（`drawHaze`）は輪の配置に残す（球では使われない）
- 族名: 遠景だけ。族の中心の上（世界座標で y＋0.2。**実装では星団の投影範囲の上端＋12px にする**。試作の置き方だと INVASION が惑星に重なった）。Jost 300・11px・字間 0.32em・大文字・不透明度 0.55×奥行き
- 族名を押す: 星団の中心へ焦点を移し倍率 3.4（遠景のまま）。族の短い名詞（R12）を族名の下に、属する惑星（主張あり）の名前を惑星の下に、**3.2 秒**（最後の 600ms で薄れる）。空を押すと原点・2.4倍へ戻る
- 惑星を押す（主張あり）: 中景へ（その惑星が中央）。もう一度押すと球（宇宙から）。空の席は押せない（`pickPlanet` の結果を `seat.n > 0` で弾く）
- 惑星名（R6）: canvas には出さない。中景で焦点の惑星の和名（22px・字間 0.22em・Noto Sans JP 300）と英名（11px・字間 0.34em・Jost 300・大文字）を **DOM で画面の高さ 61% の位置**に、0.5 秒でふわっと出す。遠景へ戻ると消える
- ピンチ・ホイール: 倍率を変える。`stageOfZoom` の閾値 4 で遠景／中景が切り替わる（既存）。遠景へ戻ったら焦点を原点に

### 4.4 書体（R10）

- `layout.tsx` に Jost（300）を `next/font/google` で足す（Noto Sans JP と同じ方法）。CSS 変数で canvas からも引けるようにし、`document.fonts.load` を待ってから初回を描く
- canvas: 英字 `300 11px Jost`、日本語 `300 10.5px "Noto Sans JP"`。`ctx.letterSpacing` を使う（**未確認: iOS Safari の対応版。非対応なら1字ずつ描く**）
- `field-render.ts` の `"Zen Kaku Gothic New"` 指定は読み込まれていないので、この機に全部 Noto Sans JP へ

## 6. テスト

- `dex.ts`: `pages[].escaping` が `rows` の離れかけ数と一致する／節の順・記事の順は既存テストのまま
- `RecallPlatePage`（DOM 無しの判断だけ）: 押した点の1行は分野ページで同時に1つ／離れかけの点は quiz、他は view（既存 `onRow` の振り分け）
- `field-cluster`: 決定性／7族の中心が互いに 0.6 以上離れている／各席が族の中心から `CLUSTER_SPREAD` 以内／退役席を含まない
- `field.ts`: `fieldLayout(counts, 'cluster')` は `fitScale` を掛けない（半径が `planetRadius` のまま）／`cameraFor('far'|'mid', 'cluster')` の倍率・焦点
- `lift-phase.ts`: 遷移表の全経路（球→宇宙→中景→球→宇宙→閉じる）
- 描画: `/dev/recall-field` を playwright で撮る。1コマの時間（ガス込み）が 8ms 以下
- 分野ページ: playwright で呼吸（仮データ 178件）の高さが 3,000px 未満
