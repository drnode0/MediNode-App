## 0. 一言でいうと

分野ページの紋章で浮き出る球（隠しコマンド D5）の下に「さらに宇宙へ」を置く。押すとカメラが引いて、
**7族ごとの星団に散らばった惑星が、自転しながら浮いている宇宙**（遠景）になる。宇宙で惑星を押すとその球へ飛べる。
主動線には影響しない。目的はオーナーの言葉で「全体の宇宙観を見せる」「美しさとして残す」。

## 1. 決めたこと（オーナー裁定・2026-09-05）

| # | 決定 | 採らなかった案 |
|---|---|---|
| S1 | 宇宙は**遠景から**開く | 中景から／既存の輪をそのまま |
| S2 | 配置は**族ごとの星団**（7族の中心のまわりに惑星を散らす） | 均一なランダム／奥行きのある帯 |
| S3 | 操作は**回す＋惑星を押すと寄る＋ピンチ／ホイールで引く寄る** | 回すだけ |
| S4 | 空の席は**薄いモヤで残す**（今の遠景と同じ） | 出さない |
| S5 | 入口は**球の画面の「戻る」の隣**。宇宙の「戻る」は覆いを閉じて分野ページへ | 宇宙の「戻る」で球へ戻す（入った順に戻る） |
| S6 | 一覧（標本帳）の紋章は今までどおり分野を開くだけ | 一覧の紋章からも球を出す（紋章がカードのボタンの中にあり、入れ子のボタンになる） |

再検討ライン: S5 は「宇宙から分野ページへ戻ったとき、どの分野にいたか分からなくなった」という声が出たら S5 の代替案（入った順に戻る）へ替える。

## 2. 動線

```
分野ページ ──紋章を押す──▶ 球（近景・D5）──「さらに宇宙へ」──▶ 宇宙（遠景）
    ▲                          │  ▲                                │
    │        「戻る」            │  │ 「戻る」（宇宙へ）                 │ 惑星を押す
    └──────────────────────────┘  └────────────────── 球（近景）◀──┘
    ▲                                                              │
    └──────────────────── 「戻る」（覆いを閉じる） ◀────────────────┘
```

- 球の画面の下に「戻る」「さらに宇宙へ」を並べる。宇宙の画面の下は「戻る」だけ
- 宇宙で惑星を押す → その惑星の近景（球）へ飛ぶ（既存の `enterNear(slot)`）。この球の「戻る」は**宇宙へ**（`backToFar`）
- 宇宙の「戻る」→ 覆いを閉じて、入る前の分野ページへ（S5）
- Esc・タブを離れる・カードの Esc の譲り合いは D5 の覆い（`RecallLift`）の実装をそのまま使う
- 宇宙で惑星の点（主張）は押せない（点が読める大きさにならない）。球へ寄ってからは D5 と同じく押せる

## 3. 配置（族ごとの星団）

新しい配置モード `'cluster'` を `FieldMode`（現行 `'ring' | 'sphere'`）に足す。席の位置 `at: Vec3` を返す純関数を1つ足すだけで、
投影・奥から描く順・寄る動線（`angleOf(seat.at)`）・空の席のモヤは既存のまま動く。

- **族の中心 7 点**: 単位球のまわりに、互いの距離が最大になる近似（黄金角の螺旋で 7 点）。族の順は `CoreKind` の定義順
- **惑星の位置**: 族の中心 ＋ 席番号から決まる固定の乱数ベクトル（既存 dev ハーネスと同じ整数ハッシュ）。星団の半径は族の中心どうしの距離の 0.35 倍を上限にする。開くたびに変わらない
- **大きさ**: 今の `planetRadius(n, max)` のまま。重なりは今の `fitScale`（全体を一律に縮める）で避ける
- **空の席**: 同じ式で位置を持ち、`summary.haze` のときは今までどおりモヤだけ（S4）
- **星団の名前**: 遠景（stage が `far`）のときだけ、族の中心の投影位置に英語の族名（Flow / Exchange / Signal / Invasion / Structure / Regulation / System）を 10px・40% で出す。中景・近景では出さない
- 位置の計算は `src/lib/recall/field-cluster.ts`（純関数・描画を知らない）に置く

## 4. 見え方と動き

- 遠景（`FAR_ZOOM` 1.5・傾き `RING_PITCH`）で開く。雲なので、輪の遠景で起きていた「上下2本の帯に潰れる」は起きない
- 空間全体は `IDLE_SPIN`（約3分で1周）で回る。各惑星の芯（7族の動き）と点の輪は今までどおり回る
- ダークは他タブと同じ紺、ライトは紙。覆いの色は D5 と同じ（`bg-[#F5F7FA]/[.92] dark:bg-[#0B1524]/[.92]`）
- 動きを減らす設定: 自転と遷移を止める（既存の `reduced`）
- 上に小さく「宇宙」の題は出さない。球のときに出している和名・英名も宇宙では消す（どの分野の画面でもないため）

## 5. 操作

すべて既存 `RecallField` の操作。ドラッグで回す（慣性あり）・ピンチ／ホイールで `zoom` を変える・惑星タップで `enterNear`。
近景（球）からの背景タップ・ホイール下・ピンチインは、D5 では「閉じる」に読み替えていたが、
**宇宙から入った球では「宇宙へ戻る」に読み替える**（`onStage('mid')` が届いたら `backToFar` 相当）。

## 7. 進め方（先にラフで見る）

段0: dev ハーネスに「配置: 輪／星団」を足し、**本物のコードが回る状態**でオーナーが見て承認する（記憶 recall-seven-cores「見た目の案は絵でなく回るコードで出す」）。
承認の観点: 7つの星団が見分けられるか／惑星が重なっていないか／スマホ幅で惑星が小さすぎないか（遠景で半径 5px 未満なら `FAR_ZOOM` を星団用に上げる）／自転の速さ。
段1以降（アプリ側への接続）は段0の承認後。

## 8. テスト

- `field-cluster`: 同じ入力で同じ位置（決定性）／7族の中心が互いに 1.0 以上離れている／各席が自分の族の中心から星団半径以内／退役席を含まない
- `fieldLayout(counts, 'cluster')`: 全席が返る／`fitScale` 後に惑星どうしが重ならない（距離 ≥ (ra+rb)×R_RING_OUTER×0.98）
- `RecallLift`: 「さらに宇宙へ」で `space` になる／宇宙の「戻る」で `onClose`／宇宙から入った球の「戻る」で `space` へ戻る／Esc の譲り合いは既存テストのまま通る
- 画面: `/dev/recall-field` を playwright で撮る（ライト・ダーク・スマホ幅・遠景・中景・近景）

## 9. 範囲外

- 帯（分野名の横並び）は宇宙に出さない
- 視点B（中心から）は宇宙では使わない（`center` は `'outside'` 固定）
- 改訂の旗（引き続き範囲外）
- 一覧の紋章から球を出すこと（S6）
- 星団の並びを主張数や離れかけで動かすこと（位置は固定）

## 10. 使わない語

振る・拾う・血肉・落ちる・定着・輪（宇宙の文脈では「星団」「宇宙」）。長いダッシュを使わない。
