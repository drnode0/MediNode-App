## なぜ作り直したか

前の芯（`torus` / `nested` / `tree` / `icosa` / `frame` / `gimbal` / `globe`）は美しくならなかった。
原因は3つで、いずれも描き方ではなく形の側にあった。

1. **線が足りない。** 立方体は辺が12本、二十面体でも30本。線が重ならないので濃淡が生まれず、
   どう描いても平たい図形にとどまる。針金細工の美しさは、巻き数の密度・重なりの濃淡・曲率から出る
2. **形が族の意味を持っていない。** 八面体・三角柱・格子は、どの族に置いても成立してしまう。
   名前を伏せて並べたとき、どれが「流れ」でどれが「交換」か言えない
3. **判断していた対象が出荷されない。** ChatGPT の静止画で見比べていたが、本番の球は
   `RecallSphere.tsx` が canvas に線で描いている。静止画を選んでも、それは実装に持っていけない

**判断はコードで回るラフで行う**、を作り直しの前提にした。

## 決めたこと

### 動きが族を分ける（形より先にこれ）

7族に、意味の違う動きを1つずつ割り当てる。**2族が同じ動きに見えたら、どちらかを変える。**

| 族 | 動き | 席 |
|---|---|---|
| 流れ | 閉じて戻る | 救急蘇生・循環・血液凝固線溶系・輸液輸血水電解質 |
| 交換 | 行って帰る | 呼吸・腎・肝胆道系・膵・消化管・代謝内分泌・栄養 |
| 信号 | 伝って分岐する | 中枢神経・リハビリPICS・精神科 |
| 侵入 | 広がって戻らない | 感染症・熱傷・急性中毒・アレルギー免疫 |
| 構造 | 撓んで耐える | 外傷整形・画像診断・手技・災害・周術期麻酔・病院前搬送 |
| 調節 | 乱れて釣り合いへ戻る | 多臓器障害・体温異常環境障害・薬剤・妊産婦・小児・移植・腫瘍血液救急 |
| 体系 | 動かない | 総論・医療倫理・集中治療医・学会・統計研究・マイナー |

派生する縛りが2つある。

- **往復は交換の専売。** 行って帰る動きを他の族に付けない（侵入で往復させない）
- **直線は構造の専売。** 曲線と巻きを基本にし、直線に意味があるのはテンセグリティだけ

### 形

| 族 | 形 | 要点 |
|---|---|---|
| 流れ | ひと続きの巻き線 | 1本の線が輪の周りを24周して必ず出発点へ戻る。巻きの重なりが濃淡を作る |
| 交換 | 二枚の編みと通路 | 外殻 r=0.94・内殻 r=0.54 の編み、両者を貫く通路9本 |
| 信号 | 分かれる枝 | 1点（下極）から3方向へ、深さ4で二叉分岐。末端ほど短く細い |
| 侵入 | 編んだ球と異物 | 極を持たない大円だけの編み（地球儀にしない）＋食い込む異物 |
| 構造 | テンセグリティ | 棒6本はどこでも接触せず、細い張力線18本で吊られて立つ |
| 調節 | 三重の輪と錘 | 直交する3つの輪＋中心の小さな錘 |
| 体系 | 六層の重なり | 他の6族を縮小して同心に重ねる。自分の形を持たない |

**編みに緯線・経線を使わない。** 極が生まれると地球儀に見え、それは体系の姿になる。
軸を球面へ等間隔（黄金角）に散らした大円だけで組む。

### 侵入の時間割（物理の順番を守る）

一撃 = 9.5秒。**触れる前に凹まない。破れる前に波紋を出さない。**

| 位置 | 起きること |
|---|---|
| 0 → 0.18 | 近づく。異物は球の外。編みは一切動かない |
| 0.18 | 触れる。先端が面に当たる |
| 0.18 → 0.34 | 一緒に沈む。**先端は常に凹みの底にいる**（凹みの深さ＝先端の深さ）。押すほど抵抗が増すので沈みは遅くなる |
| 0.34 | 破れる。凹みが深い張りから浅い穴へ跳ね返る |
| 0.34 → 1.0 | 跳ね返りが波紋になって編みを渡り、反対側で消える。戻らない |
| 以降 | 跡は浅い凹みとして残り、3回ぶんまで重なって古いものから塞がる |

次の一撃は**別の方向**から来る（黄金角で回す）。同じ点を二度は突かない。

### 描き方

- **奥行きで明暗を分ける。** 14段のバケツに分けて `globalAlpha = minA + (1-minA)·f²`、
  `lineWidth = 0.45 + 1.05·f`。既定の `minA = 0.10`。ここが狭いと平たく見える
- **光（`#F6E7B8`）は動きにだけ使う。** 流れの脈・交換の往復・信号の発火・調節の錘
- **白の温度は3段。** 温かい `#FAF2EA`（流れ・侵入の異物）、冷たい `#EBF2FB`（交換・信号・侵入の編み）、
  白 `#F4F7FA`（構造・調節・体系）
- 個体差（37席）は**大きさ・自転の軸・傾き**だけで付ける。族の中で形は変えない

### 実寸で見分けられること

芯は惑星の中で直径40px前後にしかならない。**大きくして美しくても、40pxで区別が付かない形は採らない。**
交換と侵入はどちらも編んだ球なので最も近い。潰れるなら、交換の内殻を小さくするか通路の光を強くする。

## 非目標

- ChatGPT 等での静止画生成による見比べ。判断は回るコードで行う
- 面・塗り・影。線だけで描く（LP の線画に揃える）
- 族の中での形の作り分け。個体差は大きさと軸だけ

## 実装へ

- 差し替え先は `src/components/recall/RecallSphere.tsx` の `buildCore` / `CORE_KIND` / `drawCore3D`
- ラフの座標系は芯の半径 CR を 1 とする単位で、現行と同じ。座標と描画はそのまま移せる
- 動きを減らす設定のときは、回転・光・侵入の一撃を止めて静止の姿を出す（現行の `reduced` を流用）
- 計算量が増えるので、画面外の惑星は描かない（ラフでは IntersectionObserver で実装）
