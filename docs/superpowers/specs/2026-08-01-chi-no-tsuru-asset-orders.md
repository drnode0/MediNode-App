# 知の蔓 アセット発注書（検証バッチ）2026-08-01

## 使い方（tatsukiさんの手順）

1. ChatGPT（画像生成）で新しいスレッドを1本立てる（**以後すべての生成をこの1スレッドで続ける**——画風の記憶を効かせるため）
2. **毎回、アンカー5枚を添付**（`docs/superpowers/specs/assets/style-anchor/anchor-1〜5.png`）
3. 下の【STYLE LOCK】＋各アセットの発注文を続けて貼る
4. 生成画像を**指定ファイル名**で `docs/superpowers/specs/assets/generated/` に保存（フォルダは作成済み）
5. 6点揃ったら私に一言。透過抜き→実装に載せて画風判定します（NG項目だけ再発注）

気に入らなければ同スレッドで「もっと線を軽く」「余白を増やして」等の追い指示でOK。**構図の注文より画風の一致が優先**です。

---

## 【STYLE LOCK】毎回の発注文の先頭に貼る

```
添付した5枚と完全に同じ画風で描いてください：鳥獣戯画×ジャックと豆の木の墨絵。
・軽い墨の筆線、かすれ、にじみ。淡彩（蔓と葉は灰緑、他はほぼ墨）
・特に1枚目と5枚目の「線が軽く、余白が多い」タッチに合わせる
・背景は必ず無地の生成り一色（#F2EAD6）。紙の質感・模様・風景・影は描き込まない
・文字・落款・印・枠は入れない
・対象は1つだけ、画面中央、周囲に余白（切り抜き前提）
禁止：写実的陰影、3D調、グラデーション背景、太いベタ塗り輪郭
```

## 合否の観点（私が判定）

- 5枚のアンカーと並べて違和感がないか（画風一致）
- かすれ・にじみのソフトエッジが透過抜きに耐えるか
- 蔓の節：上下を連結したとき筆致が続いて見えるか
- 兎・雀：小さく縮小しても「らしさ」が残るか

## 本番一式（検証合格後に発注書を発行）

蔓セグメント残り（若/中/古×2〜3型）・穂先バリエーション・実物23種（アリ〜立山。湯のみは検証流用）・住人（蛙/猿/狸＋茶店/狐）・住み着き生き物・空の点景（月/蛍/雲/靄/雪/雀の群れ）・地面の墨だまり・題字と落款の一点物。計45〜55点想定。

## 追加検証（2026-08-02・2点）

### 7. `leaf_single.png` — 葉（1024×1024）
```
豆の蔓の葉を1枚だけ、大きく中央に。ハート形に近い豆の葉、葉脈は墨の細線、
淡彩の灰緑。葉柄（茎につながる短い柄）を左下に向けて付ける。
1枚目・5枚目の画風。背景は無地の生成り一色。文字・印なし。
```
用途: ゲーム内の全ての葉の「型」（マスク彩色で青葉/色褪せ/照り葉に塗り分ける）。合格したら形違いをもう1〜2枚。

**検証結果（2026-08-02）: 合格。** アルファの濃淡がそのまま「型」として立ち、平塗り1色で青葉/照り葉/色褪せ/輪郭の4状態を塗り分けられることをデモ（`assets/2026-08-02-vine-growth-polish.html`）で確認。実測値は下記。オーナーの完成形答え合わせ待ち。

- アンカー（葉柄の先）＝ **(20.3%, 81.3%)**。配置・鏡像・回転すべてこの点を原点に取る
- 葉身長 ÷ 型の一辺 ＝ **0.786**（アンカーから最遠点まで）
- アルファ実測 **線 .867 / 葉身 .298**（比2.91）→ マスクをn乗して線だけ抜ける。**3乗が上限**（線.651／葉身.026＝比24.6倍。4乗だと線が.564まで落ちて見えなくなる）
- 塗りを2枚重ねると実効α ≈ .51 まで上がる＝「照り葉」の密度に使える

**追加で必要になった型（2026-08-02の裏取りから）**

葉は決定成長なので「先端の小さい葉＝これから大きくなる（未展開）」「基部の小さい葉＝もう大きくならない（成熟して小さい）」を描き分けたい。基部は既存の型を小さく使えばよいが、**未展開の葉は形が違う**。

```
（STYLE LOCKに続けて）
同じ豆の蔓の、まだ開ききっていない若い葉を1枚。芯から巻いた状態から
半分ほどほどけかけた、細く丸まった形。葉脈はまだ薄く、輪郭の墨も細い。
葉柄を左下に向けて付ける。背景は無地の生成り一色。文字・印なし。
```
ファイル名 `leaf_young_furled.png`。用途＝穂先の展開途中の葉。**形違いの成葉をもう1〜2枚**（`leaf_single_b/c.png`）も同時に。

### ❗ 見落としていた必須アセット：双葉（2026-08-02発見）

`src/lib/vine-leaves.ts` は葉を3型に分けている（`outline` / `futaba` / `green`）。このうち **`futaba`＝「書いた」で生える双葉の型がまだ発注されていない**。検証デモでは成葉を小さく左右一対にして代用しているが、双葉は本来まったく別の形（子葉2枚）。「自分で書いた」は最も希少で褪せない行為なので、ここが代用のままだと世界観の要が抜ける。

```
（STYLE LOCKに続けて）
豆の芽生えの双葉を1枚だけ、大きく中央に。地際から出た短い茎の先に、
丸みのある子葉が左右対称に2枚ひらいた形。まだ本葉は出ていない。
葉脈はごく淡く、輪郭は細い墨線。淡彩の灰緑。
背景は無地の生成り一色。文字・印なし。
```
ファイル名 `leaf_futaba.png`。用途＝`wrote` の葉（褪せない・希少）。

### 地下茎（2026-08-02・v2設計で新規）

持ち込んだ知識を「地面の下で既に伸びていた蔓」として描くための型（`2026-08-02-chi-no-tsuru-v2-design.md` §7）。**地上部と接続して1本に見えること**が最重要。

```
（STYLE LOCKに続けて）
豆の蔓の地下茎を、横長の構図で。画面を左右に横切るように這う太い茎で、
節がいくつかあり、節から細い根が下へ何本も伸びている。
節には、まだひらいていない小さな鱗片状の芽がいくつか付いている。
茎の中ほどから、上へ向かう短い芽が1本だけ立ち上がっている（地上へ出る手前）。
土は描かない。背景は無地の生成り一色。断面図の枠線・地面の線は描かない。
文字・印なし。
```
ファイル名 `rhizome_a.png`（横長 1536×1024）。

**判定基準**：①上へ立ち上がる芽が地上の蔓と自然につながるか ②「断面図」に見えず絵として成立するか ③薄墨に落としたとき（地下は淡く描画する）形が読めるか。

合格したら長さ違い・節数違いを2〜3枚（`rhizome_b/c.png`）。持ち込み量に応じて横に連ねる。

### 8. `resident_suzume_fly.png` — 雀・羽ばたき（1024×1024）
```
添付した雀（resident_suzume.png）と完全に同一個体・同じ画風で、
「羽を広げて飛び立つ瞬間」のポーズ。右向き。背景は同じ無地の生成り一色。
文字・印なし。対象は1羽だけ、中央に余白を残して。
```
