# リーダー末尾「つづけて読む」枠（関連ナレッジ＋根拠文献の自動表示）設計

日付: 2026-07-29
ステータス: spec化済（実装計画は未作成）
前提: feat/subscription-inapp-reader（アプリ内リーダー）のマージ後に実装する

## 背景

- 2026-07-29に、CQ・ナレッジの本文から「📖 参考文献」節をテンプレ廃止した（スキル
  medinode-cq-note / medinode-knowledge-promote / medinode-next-step、およびNotion正典
  「🧭 CQパイプライン指示書」を更新済み）。文献の紐づけは Reference Library 側の
  「関連ナレッジ」リレーションのみ（ナレッジ側 `参考文献` プロパティに自動反映）。
- 本文📖節の廃止で、アプリ内リーダーで読む会員には文献への導線が本文からは消える。
  その受け皿と、読了後に「次に読むもの」へ進む導線を、リーダー末尾に自動表示で作る。
- 旧フォーマットの本文「関連ナレッジ」節は手動維持で腐るため過去に廃止済み。
  手動キュレーションは行わない（オーナー決定 2026-07-29）。

## 目的

サブスク会員がナレッジを読み終えた位置に「つづけて読む」枠を出し、
(a) 関連ナレッジ、(b) このナレッジの根拠文献（📄精読ノート/🔖文献カード）へ
ワンタップで遷移できるようにする。

## 表示仕様

- 位置: アプリ内リーダーの本文末尾（免責の下）。読了位置に自然に現れる。
- 構成: 2グループ。
  1. **根拠文献** — このナレッジの `参考文献` リレーションに実登録された
     Reference Library ページ。収録レベルバッジ（📄/🔖）付き。0件なら見出しごと非表示。
  2. **関連ナレッジ** — 自動算出。同一詳細ジャンル > 同一ジャンル の優先で、
     キーワード重複でスコアリングし上位3件程度。自分自身と閲覧中ページは除外。
     タップでリーダー内遷移（リーダーを閉じない）。
- 手動キュレーション用のプロパティ・本文節は作らない。
- トーン: 宣伝調にしない（「つづけて読む」等の静かな見出し。AI主役の文言NG）。

## 実装が必要な変更（調査ポイント含む）

1. **sync拡張**: 現行の /api/sync はリレーションを同期していない。サブスク Medical_DB の
   `参考文献` リレーション（ページID配列）を検索インデックスへ追加同期する。
2. **関連ナレッジ算出**: 同期済みインデックスにあるジャンル・詳細ジャンル・キーワードで
   アプリ側計算（Notion追加APIコールなし）。スコアリングは軽量でよい。
3. **リーダーUI**: feat/subscription-inapp-reader のリーダーコンポーネント末尾に枠を追加。
   リーダー内遷移の履歴（戻る）挙動を確認。
4. **文献タブとの整合**: 収録レベルバッジは既存 ResultCard の琥珀系配色を踏襲。

## やらないこと

- Notion本文への関連ナレッジ節・📖節の復活（腐るため）。
- Notionで読む会員向けの追加施策（リレーションのプロパティ欄表示で足りる。
  プロパティが非表示設定になっていないかはオーナーが目視確認）。
