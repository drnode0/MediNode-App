# 知の塔（仮）— MediNode本体の成長ゲーム 設計（2026-08-01）

## 背景と目的

MediNodeの最大の弱点はリテンション（続ける理由の弱さ）。別アプリ「知の庭」で育成表現を試みたが、①一回の行為の帰結が小さすぎて感じられない ②自動で増えるものは手応えが薄い ③和の世界観がMediNodeのブランドと別宇宙、の3点で「毎日育てたくなる」に届かなかった（庭は鑑賞用の別邸として凍結）。

この機能はその反省の上に、**MediNode本体の中に**「ナレッジが積み上がる喜び・ゲーム感覚で知識を増やす楽しみ」を作る。対象は**全ユーザー**（書く人も、サブスクを読むだけの人も）。

決定の経緯: 7視点（ゲームクリエイター/集中治療専門医/一般ユーザー/学習科学者/事業/実装/2年後のパワーユーザー）の議論を2周。スキンは3案（A夜ドット・Bソフト物理・C石積み）の比較モックからオーナーが**B**を選定。

## ゲームの核 — 三層ループ

**塔がただ純粋に高くなる。** それだけ。ただし三つの時間スケールでループが回る:

1. **秒**: 学ぶたびブロックが降ってきて、ぽよんと弾んで塔に載る
2. **日〜週**: 「あと12歩でネコ」——次に越す実物が常に見えている。アリ→テントウムシ→スズメ→ネコ→柴犬→ヒト→ゾウ→…
3. **月〜年**: 30歩ごとに「第n巻」に綴じられ地層になる。年末に年鑑。振り返ると自分の歴史が巻の縞で読める

## 歩（ブロック）の規則

**1歩＝1ブロック＝知識1件の段階遷移1回。** 段階遷移のみが積む（再読・再回答は積まない）:

| 遷移 | 検知源 |
|---|---|
| 初めて読んだ | リーダー開閲（既存の「最近見た」系の端末記録） |
| 書いた | Algoliaレコードの存在（作成日で初日から遡って積める） |
| 初めて即答できた | 既存 `quiz-srs`（`medinode_quiz_stats`）の初回ok |
| CQが解決した | 既存 resolved-cqs |
| くすみから磨き直した | 要再確認→再度ok（本物の学び直しなので積む） |

- 1件の知識は最大3〜4回塔を伸ばす。読むだけの人も、書く人も、毎日塔が動く
- **量産ゴミ知識の防波堤**: 「書いた」だけでは1歩止まり。上の歩は想起（クイズok）を通らないと積めない
- 学習効果の序列（読む<書く<思い出す）がそのまま歩の獲得順になっている

## スキン — B: ソフト物理（確定）

比較モック: `assets/2026-08-01-chi-no-tou-compare.svg`（A夜ドット案の参照: `assets/2026-08-01-chi-no-tou-arcade-ref.svg`）

- **昼のトーン**: 空色→薄緑のグラデ背景・白い巻カード・MediNodeの常盤/パステルと地続き
- **ブロック**: 角丸の柔らかい塊（rx大きめ・上面ハイライト）。ジャンル色。±2〜4°の回転と数pxのオフセットで「物理で積まれた」佇まい
- **物理は演出（choreographed）であってシミュレーションではない**: 決定的・崩れない・matter.js等の物理エンジンは入れない。落下→squash（一瞬つぶれる）→塔がわずかに揺れる→収まる、をCSS/WAAPIのspring系イージングで作る
- **状態の描き分け**: 輪郭のみ＝読んだだけ／ベタ＝書いた／**若葉**（ブロックからはみ出す）＝即答できる／彩度が落ちてグレーに寄る＝要再確認（くすみ）
- **目盛りの動物は「住人」**: ソフトな後ろ姿シルエット（モックのネコ参照）。定規ではなく、塔の隣で待っている存在として描く。越える瞬間に小さく反応する（跳ねる・飛び立つ）
- 音なし。祝いは既存 `pop` 級の小ささまで。`prefers-reduced-motion` は全演出静止

## 画面と動線

- **ホーム（検索タブ）にコンパクトカード常設**: 1行——高さ・今週+n・「あと n歩で◯◯」。開いて5秒で現在地（医師の当直の合間ルール）。歩の発生直後はカード上で `+1` が pop
- **タップでフル画面**（オーバーレイ）: 塔の全景。**下にスクロールすると過去へ**（巻の地層・「2026.3 スズメを越えた」の埋め込みマーク）
- **差分積み**: フル画面を開いた時、前回見た高さ（端末記録）から新しいブロックが1個ずつ降る（8個超は束＋`+n`）。**Notionで書いた学びが、開いた時にまとめて積まれる——自分の仕事の収穫として**
- **越え演出**: 目盛りを越える瞬間は一拍おき、動物が反応して下へ流れ、一度だけカード「スズメを越えました 15cm」（画像保存ボタン付き）

## 目盛りの梯子（ドラフト・実装時に監修する調整可能定数）

1歩＝1mm（**初期値・調整可能な定数**。モック内の cm 表示はダミー値であり、この換算とは一致していない）。序盤密・実寸・品のある選定（自然物と暮らしの物。悪ふざけ禁止）:

| 歩 | 実物 |
|---|---|
| 3 | アリ 3mm |
| 8 | テントウムシ 8mm |
| 30 | ペットボトルのキャップ 3cm |
| 50 | 単3電池 5cm |
| 100 | 湯のみ 10cm |
| 150 | スズメ 15cm |
| 300 | ネコ（座高）30cm |
| 500 | 柴犬（体高）50cm |
| 800 | デスク 80cm |
| 1200 | コウテイペンギン 1.2m |
| 1700 | ヒト 1.7m |
| 3200 | アジアゾウ（肩高）3.2m |
| 5000 | キリン 5m |
| 12000 | 電柱 12m |
| 15000 | 奈良の大仏 15m |

- 2年の実利用（600件超・歩換算1500前後）で**ヒトが現実的な長期目標**になる規模感。ゾウ以降は「ずっとそこにある山」
- 越えた目盛りは塔の脇に✓付きで残る（履歴＝時間遡行スクロールで再会する）

## 巻（30歩ごとの製本）

- **通算30歩・時系列**で「第n巻」に固まる（ジャンル不問——分散する人も読むだけの人も必ず30歩ごとに巻が生まれる）
- 巻カードに**その30歩のジャンル縞**（＝地層）と葉の数。専門を深めた人はほぼ一色、広く歩いた人は縞になる。どちらも正直な自画像
- **巻は製本後も熟す**: 中の知識が後から「書いた」「即答できる」に上がれば、縞が濃くなり葉が増える
- タップで**巻をめくる**: その30歩の日付・知識名・遷移の一覧（「この頃、敗血症ばかり学んでいた」が読める）

## くすみ（要再確認）

- 「即答できる」は永続しない。最終ok から N日（初期値90・調整可能）で、その知識のブロックが**くすむ**（彩度が落ちる）。塔は縮まない——積んだ事実は消えない
- 呼称は「**要再確認**」。医学的に誠実な事実であって罰ではない。磨き直せば色が戻り＋1歩積まれる
- 語彙の全面禁止: 「制覇」「マスター」「コンプリート」「枯れ」

## 振り返り機能群（長く使うための核）

1. **年鑑**: 年末に「2026年の塔」が1枚に固まる——伸びた高さ・綴じた巻数・ジャンル地層・一番積んだ月・初めて葉が付いた知識。**画像書き出し**（canvas→共有/保存）
2. **巻をめくる**（上述）
3. **去年の今日**: フッターのログに時々「去年の今日、◯◯を書いた」（庭の「今日の一枚」の生まれ変わり）
4. **塔スクロール＝時間遡行**: 全景を下へ辿ると、巻の地層と「◯月◯日 スズメを越えた」の印が埋まっている

## データ設計（v1・端末ローカル・新インフラなし）

- **新キー** `medinode_tower_v1`: 歩の台帳 `{ steps: [{id, kind: 'read'|'wrote'|'recall'|'resolved'|'repolish', at, genre}], lastSeenSteps, lastSeenAt }`（上限管理は quiz-srs の MAX_ENTRIES 方式に倣う）
- 検知はすべて既存機構への薄いフック: リーダー開閲・Algolia同期（wrote のバックフィル含む）・`recordQuizResult`・resolved-cqs
- **初日から積み上がった状態で始まる**: wrote はレコード作成日で遡行構築（ゼロスタート禁止）。read の遡行は既存の閲覧履歴の範囲まで（限界として明記）
- genre が無いレコードは「未分類」の色（グレー系）で受ける
- ホームカードは**追加API呼び出しゼロ**（手元のインデックス統計とlocalStorageのみ）
- 既知の限界: 端末間で歩がズレる（v1は割り切り。将来、既存の設定同期の暗号化チャネルに載せて解消可能）

## 料金の線（未決・両案併記。実装直前・告知先行の段階で決定）

- **案A**: 塔・巻・年鑑・演出は全部無料。磨く道具がプレミアム——回診キュー（今日この5件を磨く采配）・ジャンル別ドリル・くすみ予報（「来週3個くすみます」）
- **案B**: 塔は無料、巻の中身・年鑑もプレミアム
- 原則: **喜びの本体（見えること）を削らない**。売るのは解決ではなく効率。くすみは無料でも1件ずつクイズで磨ける
- ログの導線「今日の回診へ」は、無料では既存クイズ（自力で磨く）へ、プレミアムでは采配キューへ向ける（同じ文言で行き先が変わるのは不誠実なので、無料側の文言は「クイズで磨く」等に変える）

## 守る原則（禁止事項）

- 報酬は**情報のみ**。ポイント・通貨・ガチャ・ストリーク永久禁止
- 音なし。祝いは小さく。`prefers-reduced-motion` 尊重
- ゲームの語彙・演出はこの機能の枠内のみ（MediNodeの他画面は静かなまま）
- 病棟で見られて恥ずかしくないこと（子供っぽさ・悪ふざけの目盛り・誇大な称号の禁止）
- Dr.テトは v1 に入れない（塔の隣にスプライト枠だけ将来予約）
