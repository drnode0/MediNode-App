# モニターFB第2弾 UX改善 設計（2026-07-18）

公開当日（20:00）に受けたモニターフィードバック4点への修正設計。
対象はセットアップ画面（`src/components/SetupWizard.tsx`）のみ。

## 背景（フィードバック原文の要旨）

1. 「使い方」「ガイド」「ヘルプ」の3つがあり、どれを選べばよいか分かりにくい
2. 戻るボタンが左上にあったり下にあったりして見つけにくい
3. トークンの連携設定が「なんか大変」と感じる
4. セットアップ途中に「あとで設定して先に中身を見る」逃げ道が見当たらない

## 修正1: ヘルプ入口を1つに統合

現状、ウィザードのヘッダーに3つの入口がある:
- 左上「使い方」→ オンボーディング（アプリ紹介）再表示（`onShowOnboarding`）
- 右上「ガイド」→ Notion説明書を別タブで開く（外部リンク）
- 右上「ヘルプ」→ ステップ別ヘルプシート（`STEP_HELP` + FAQ検索）

変更:
- 左上「使い方」ボタンと右上「ガイド」リンクを**撤去**し、右上「ヘルプ」だけ残す
- ヘルプシート内の `STEP_HELP` 本文の下（FAQ検索ボタンの上）に2行のリンクを追加:
  - 「アプリの紹介をもう一度見る」→ シートを閉じて `onShowOnboarding()` を呼ぶ
  - 「詳しい説明書（ガイド）を別タブで開く」→ 既存のNotion外部リンク
- 右上の `AccountButton`（ログイン）は現状維持
- 「迷ったら右上のヘルプから…」の誘導ヒントは現状のまま有効

## 修正2: 「戻る」をカード左上に統一

現状はステップにより「カード上部の小さな灰色リンク」（notion・options）と
「カード下部の戻る/次へペア」（sync・algolia入力後半）が混在。

変更:
- **最初のステップ以外のすべてのステップ**で、カード内最上部の同じ位置・同じ見た目
  （小さな灰色テキスト `← 戻る`）に戻るリンクを表示する。遷移は既存の
  `goPrevStep()`（steps配列基準）または各所の既存ハンドラを使う
- 下部の「戻る/次へ」ペアは**そのまま残す**（両方あっても迷わない。位置の予測可能性が目的）
- entry（入口分岐）は対象外

## 修正3+4: 「あとで設定して先に中身を見る」逃げ道

`skipMode = !targets.personal` のとき steps は `start → options` になり、
プレミアム単独（アカウント登録＋自動3日トライアル）で `isSetupComplete()` が成立する
（`subscriptionAppId + subscriptionSearchKey` のOR判定）。この既存経路へ切り替える
リンクを、詰まりやすいステップに置く。

変更:
- **notion / algolia / sync** の各ステップのカード下部に、静かなトーンのリンクを追加:
  - 文言案: 「設定はあとにして、まず中身を見てみる（プレミアム3日間無料）」
  - 補足小文字: 「入力した内容は保存されます。Notionの設定はあとから 設定 → 接続 で再開できます」
- 押したときの動作:
  1. `setTargets({ personal: false, team: false, premium: true })`
  2. `setOpenSection('subscription')`（既存の自動展開はopenSectionが空のときだけなので明示的に）
  3. `setStep('options')`
- 入力途中のトークン等は `saveDraft` が既に入力のたび保存しているため消えない
- Notionステップの見出し付近に目安を1行追加: 「目安は約5分。あとからでも設定できます」
  （修正3の「大変そう」への直接の手当て。過剰な励まし文言は入れない）

## 影響範囲・やらないこと

- 変更ファイルは `SetupWizard.tsx` のみ（`STEP_HELP` 定義含む）
- `OnboardingScreen` / `SettingsPanel` / API / 完了判定ロジックは変更しない
- 引用リポストの件は情報共有のみで作業対象外

## 検証

1. `rm -rf .next && npx tsc --noEmit && npm test && npm run build`
2. dev サーバーで実画面確認:
   - ヘッダーがヘルプ1つになり、シート内から紹介・説明書へ到達できる
   - 各ステップの左上に戻るが常に出る（mode→notion→algolia→sync→options）
   - notionステップで逃げ道リンク → options のプレミアム節が開いた状態で遷移
3. デプロイはオーナー確認後に main へ push（Vercel自動デプロイ）
