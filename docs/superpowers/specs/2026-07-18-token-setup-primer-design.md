# Token躓き改善：プライマー＋ガイド埋め込み 設計

日付: 2026-07-18
起点: モニターFB（Dr.イルカ）
- 「トークンのところですでに躓いています」
- 「説明が悪い・冗長ではない。概念の説明から入らないといけないので文字量を削るのは難しい」
- 「インストールしてすぐやろうとして、読まずに進めると『トークンとはなんぞや？』で躓く。先に説明を読めばすぐできそう」

## 問題の定義

躓きの本質は文字量そのものではなく、次の2つ。

1. **概念の壁**: トークン＝「アプリにNotionを読ませる合鍵」というメンタルモデルがないまま手順に入ると、操作の意味がわからず不安になる。
2. **行動パターンの壁**: 多くのユーザーは「まずやってみて、詰まったら読む」。現状のNotion設定画面（`SetupWizard.tsx` の `notion` ステップ）は「先に読んで理解してから」を前提に、同じことを教える入口が4つ（画面つきガイド・動画・テキスト手順・note）＋今は関係ない注記（部署用DB等）を同時に見せており、初見では「どこを読めばいいのかわからない」。

## 決定事項

- 方針: **10秒プライマー＋ガイド直行**（概念を3行で渡し、そのまま画面つきガイドへ流す）
- 実装形: **既存 `NotionTokenGuide` にToken貼り付け欄を埋め込む**（サブステップ分割の大改修はしない）

## 設計

### 1. Notion設定画面の初期表示を「プライマー＋1ボタン」に減量

`src/components/SetupWizard.tsx` の `notion` ステップ冒頭を作り替える。初期表示は3要素のみ。

- **プライマーカード**（🔑アイコン＋3行・静かな文体）:

  > これから、Notionとこのアプリをつなぎます。
  > アプリはあなたのNotionを勝手に読めません。Notion側で合鍵（コネクトToken）を作ってアプリに渡し、読ませたいDBに鍵を差します。
  > 画面の通りに進めれば、目安は約5分です。

- **大ボタン「画面を見ながら進める」**: 既存 `NotionTokenGuide` を起動。唯一の主動線。
- **コネクトToken入力欄**: 形式チェック（`ntn_` / `secret_`）は現状維持。

### 2. 折りたたみに移すもの（削除はしない）

「他の方法と補足」という1つの `<details>` に格納:

- 動画で通しで見る（約3分）
- テキスト手順（慣れている方向け: notion.so/my-integrations → …）
- 部署用DB・別Tokenの注記
- Notion入門（note）リンク

### 3. ガイドへの入力欄埋め込み

`NotionTokenGuide` に props を追加し、フォームと双方向同期する。

- **Step 3「アクセストークンをコピーする」**: 本文下に貼り付け欄＋形式OK表示。Notionでコピー→アプリに戻った瞬間に目の前に貼り付け欄がある状態にし、「モーダルを閉じて入力欄を探す」工程を消す。未入力でも「次へ」で進める（塞がない）。
- **最終ステップ「ページに追加で接続完了」**: Medical DBのURL欄を埋め込み（同期・任意入力）。ガイドを閉じたら残りは「次へ」を押すだけ、を理想形とする。

props案: `tokenValue` / `onTokenChange` / `dbUrlValue` / `onDbUrlChange`（後2つは省略可能にし、connect導線からの単独起動でも壊れないようにする）。

### 4. やらないこと

- ウィザードのステップ機構の再構成（サブステップ分割）: 公開直前のためデグレードリスク回避
- ガイド8ステップの文言・画像の変更: 実績ある部品はそのまま
- 紹介ページ（セットアップガイド）側の文字量削減: 別課題として切り離し

### 5. 検証

- プレビューをスマホ幅（375px）で起動し、初見フロー（entry → personal → notion）を通しで操作確認
- 確認項目: Token欄の双方向同期／形式チェック／折りたたみ開閉／ガイド内貼り付け→閉じた後のフォーム反映／connect単独起動（テンプレ複製後導線）の非破壊
- 既存テスト（vitest）が通ること
