知　の　蔓　v2　図　解

①　画　面　の　構　造　が　変　わ　る

あの「葉95枚の壁」は、背比べのために蔓全体を画面に収めようとしたから生まれたものでした。 スクロールで辿るなら、葉は何枚あっても触れる大きさを保てて、壁そのものが消えます。

②　越　え　た　印　が　背　比　べ　と　目　次　を　兼　ね　る

越えた実物を、越えた時点の葉の位置に印として置きます。下へ辿ると「ここでスズメを越えた」と通り過ぎる。 背比べが常設の縮尺と場所を取り合うのをやめて、旅の途中で出会う出来事になります。 ラダーは全24段しかないので、これがそのまま目次になり、タップで飛べます。

③　複　利　の　罠（自己レビューで発見）

3つの定数は独立ではなく 複利開始枚数 × 率 = 1 で結合していました。125×0.008＝1。 この等式が成り立つときだけ、境界で「1枚あたり2mm」が途切れずにつながります。

私が提案した「率だけ0.0034に下げる」をやると、複利が始まった瞬間に伸びが 2mm→0.85mm（58%減）に落ち、2mmに戻るのは葉379枚。約250枚のあいだ 「複利が始まったのに減速している」状態が続きます。

だから選ぶのは率ではなく複利開始枚数で、率はその逆数になります。

④　定　数　を　こ　う　変　え　る

複利開始 125枚 → 200枚（＝40cm、一升瓶39.8cmの直後）。率 0.8% → 0.5%。 富士山まで葉2036枚＝週2件で6.8年・週1件で13.6年。 最初の200枚は完全に線形なので、序盤の手応えは現行と1mmも変わりません。

複利開始をネコ（0.4年）から一升瓶（0.7年）へ後ろにずらしたのは、 複利は「続けたこと」への報酬として届くべきだからです。

⑤　雲　の　先

富士山を越えたら測るのをやめ、比べる相手が「自分の去年」になります。 去年の今日いた高さに印が立つ。宇宙ステーションを足すような世界観の嘘をつかず、 新しいアセットも要らず、絶対に尽きません。
