# 🏥 Medical Search

NotionのデータベースをAlgoliaで高速検索するWebアプリです。
URLを開いて手順通りに進めるだけで、自分のNotionデータベースの検索環境が構築できます。

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fdrnode0%2Fmedical-search-template)

---

## ✨ 機能

- 🔍 **高速全文検索** — Algoliaによるリアルタイム検索
- 🆕 **新着タブ** — 今日・今週・今月別に表示
- 🗂 **ジャンル別ブラウズ** — カテゴリで絞り込み
- 📖 **参考文献タブ** — 発行年・更新日でソート
- 🧠 **クイズタブ** — 知識確認に
- ⚙️ **アプリ内セットアップ** — URLを開いて手順通りに進めるだけ
- 🔌 **接続テストボタン** — 同期前にAPIキーの接続を確認
- 💾 **セットアップ途中保存** — 入力中の内容を自動保存、途中で閉じても再開できる
- 🔄 **画面内で再同期** — セットアップ画面に戻らず、検索画面から直接データ更新が可能
- 🕐 **最終同期日時表示** — いつ同期したかをひと目で確認
- 🌙 **ダークモード対応** — OS設定に合わせて自動切替

## 🚀 セットアップ手順

### 必要なもの（すべて無料）

| サービス | 用途 | 登録リンク |
|---------|------|-----------|
| Notion | データベース | [notion.so](https://www.notion.so) |
| Algolia | 検索エンジン | [algolia.com](https://www.algolia.com) |
| Vercel | アプリのデプロイ | [vercel.com](https://vercel.com) |

---

### Step 1: Notionテンプレートを複製する

> 📌 **このステップの目的**
> 医療知識を入力するためのデータベース（表）をあなた自身のNotionアカウントに用意します。
> このテンプレートをコピーすることで、必要な項目（タイトル・ジャンル・タグなど）がはじめから揃った状態でスタートできます。

→ **[📋 Notionテンプレートを複製する]**（リンクは別途案内）

複製後、テンプレートのDBに自分の医療知識を入力してください。

---

### Step 2: Notion Integrationを作成する

> 📌 **このステップの目的**
> このアプリがあなたのNotionデータベースを読み取るための「鍵（アクセス許可）」を発行します。
> IntegrationとはNotionの外部連携機能のことで、ここで発行するTokenが「合言葉」の役割を果たします。

1. [notion.so/my-integrations](https://www.notion.so/my-integrations) にアクセス
2. 「新しいインテグレーション」を作成
3. 表示される **Integration Token（`secret_`で始まる文字列）** をメモ
4. DBページ右上「…」→「接続先に追加」→ 作成したIntegrationを選択
5. DBのURL `https://www.notion.so/xxxxxxxx...` をそのままコピーしておく（アプリが自動でDB IDを抽出します）

---

### Step 3: Algoliaアカウントを作成する

> 📌 **このステップの目的**
> 検索機能を動かすエンジンを用意します。
> Algoliaはキーワード検索を高速に行ってくれるサービスです。無料プランで十分使えます。
> ここで取得するAPIキーは、アプリがAlgoliaに「データを保存する」「検索する」ために必要です。

1. [algolia.com](https://www.algolia.com) でアカウント作成（無料）
2. ダッシュボード → **Settings → API Keys** を開く
3. 以下の3つをメモ：
   - **Application ID**
   - **Search-Only API Key**
   - **Admin API Key**

---

### Step 4: Vercelにデプロイする

> 📌 **このステップの目的**
> 検索アプリをインターネット上に公開します。
> Vercelはアプリを無料でホスティング（公開・運用）してくれるサービスです。
> ここで作成したURLがあなた専用の検索アプリのアドレスになります。スマホからもアクセスできます。

1. 上の **「Deploy with Vercel」ボタン** をクリック
2. GitHubアカウントでログイン（または新規作成）
3. リポジトリ名を入力 → **Deploy**
4. デプロイ完了後、表示されたURLを開く

> 環境変数の設定は**不要**です。アプリ内で入力できます。

---

### Step 5: アプリ内セットアップ

> 📌 **このステップの目的**
> Step 2・3で取得したTokenとAPIキーをアプリに登録し、NotionのデータをAlgoliaに取り込みます。
> この「同期」を行うことで、はじめて検索が使えるようになります。
> 入力内容はあなたのブラウザにのみ保存され、外部に送信されることはありません。

デプロイしたURLを開くと自動的にセットアップ画面が表示されます。

1. **Notion設定** — Integration TokenとDB IDを入力（NotionのURLをそのまま貼ればOK）
2. **Algolia設定** — App ID・各APIキーを入力
3. **接続テスト** — 「🔌 接続テスト（推奨）」でAPIキーが正しいか確認
4. **同期** — 「同期開始」ボタンをクリック → 完了🎉

> 途中で閉じても入力内容は自動保存されるので、続きから再開できます。

## 📁 Notionデータベースのスキーマ

### Medical DB（医療知識）

| プロパティ名 | 種類 | 説明 |
|------------|------|------|
| 名前 | タイトル | 知識のタイトル |
| ジャンル | セレクト | 大分類 |
| 詳細ジャンル | セレクト | 小分類 |
| タグ | マルチセレクト | キーワードタグ |
| 知識レベル | セレクト | レベル分類 |
| AI要約 | テキスト | 内容の要約 |
| キーワード | テキスト | 検索用キーワード |

### Reference DB（参考文献）※任意

| プロパティ名 | 種類 | 説明 |
|------------|------|------|
| 名前 | タイトル | 文献タイトル |
| 著者 | テキスト | 著者名 |
| ジャーナル名 | セレクト | 掲載誌 |
| 発行年 | 日付 | 発行年月日 |
| エビデンスレベル | セレクト | EBMレベル |
| キーワード | テキスト | 検索用キーワード |

## 🔄 データの再同期

Notionのデータを更新した後は再同期が必要です。

1. 検索画面の一番下にある「🔄 データを再同期する」をタップ
2. 「同期開始」ボタンをクリック → 完了

> セットアップのやり直しは不要です。同期だけ行えばデータが最新になります。

---

## 🛡 セキュリティについて

- 入力したAPIキーは**お使いのブラウザのみ**に保存されます
- 外部サーバーには保存・送信されません
- 別のデバイスからアクセスする場合は再入力が必要です
